# 🔥 Mechawi El Ikhwa

A simple restaurant management and food ordering website built with **PHP, MySQL, Bootstrap, and JavaScript**.

## 📌 About

**Mechawi El Ikhwa** is a web application for a restaurant that allows customers to browse available dishes and special offers, while administrators can manage the restaurant content through a dedicated dashboard.

## ✨ Features

### 👤 Customer Side

* 🏠 Home page
* 🍔 Browse food menu
* 🏷️ View special offers
* 📄 View food details
* 📱 Responsive design
* 📞 Contact and social media links

### 🔐 Admin Dashboard

* 🔐 Admin authentication
* 📊 Dashboard statistics
* 🍽️ Manage food items
* 🏷️ Manage offers
* 👥 Manage users
* ⚙️ Manage website settings
* 🕒 Session timeout and security settings
* 📱 Responsive admin dashboard

## 🚀 Installation

### 1. Copy the Project

Place the project inside the XAMPP `htdocs` directory:

```text
C:\xampp\htdocs\Mechawi El Ikhwa
```

### 2. Start XAMPP

Open the XAMPP Control Panel and start:

* **Apache**
* **MySQL**

### 3. Configure the Database

Create a MySQL database using **phpMyAdmin**.

Then configure the database connection in:

```text
config/database.php
```

Make sure the database name, username, password, and host match your local MySQL configuration.

### 4. Run the Project

Open your browser and visit:

```text
http://localhost/Mechawi%20El%20Ikhwa/
```
